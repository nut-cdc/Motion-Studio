# Motion Studio EXE Builder
This pack uses GitHub Actions (a hosted Windows runner) to build a portable Windows EXE without requiring admin rights on your PC.

1. Create a GitHub account if needed.
2. Create a new repository and upload the files in this folder.
3. Open Actions > Build portable Windows EXE > Run workflow.
4. Download the artifact named MotionStudio-Windows-Portable.

Alternatively, `build_windows.bat` builds locally if Python/pip installation is permitted. The portable EXE has not been tested in this environment.
